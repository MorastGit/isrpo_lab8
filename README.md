## Что изучено
- void метод не возвращает ничего (но это не значит, что он не может ничего отправить в консоль), метод с return возвращает указанное значение и это значение может быть помещено, например, в переменную
- в метод можно передавать переменные и использовать их внутри метода локально
- методы удобны чтобы избавиться от повторения кода, с методами программа читается лучше, а также для ускорения работы над программой (повторное использование и тп). например, если метод был использован в разных частях программы, при устранении ошибок можно будет исправить ее только в самом методе, вместо того чтобы исправлять везде
